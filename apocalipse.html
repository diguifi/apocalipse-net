How to use it

Send and receive on the same FM channel, with the radio set to ordinary voice audio. A full cycle repeats until stopped, so a late receiver or a missed packet can catch the next pass.

Pages and local files are limited to 256 KiB total. The preview blocks scripts and network resources. Transfers can take minutes at 1200 baud.

Works from this local HTML file in browsers that allow microphone access on file://. Chrome, Edge and Firefox generally treat local files as secure contexts; browser permission settings may still block access. WAV output needs no microphone permission.
